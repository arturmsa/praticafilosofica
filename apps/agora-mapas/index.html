Como usar
  • Toque num nó para selecionar e arrastar.
  • Arraste o círculo azul até outro nó para ligar.
  • Toque duas vezes num nó para editar.
  • "Organizar" arruma o mapa e reduz cruzamentos.
  • Para comparar dois alunos: Menu, Meus mapas, Abrir, Juntar.
